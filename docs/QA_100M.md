# IARM-X 100M QA

This revision adds the 100M two-stage FineWeb-Edu 10BT -> UltraChat training recipe.

Validated locally:

- Python bytecode compilation succeeds for `iarmx`, `scripts`, and `tests`.
- Full pytest suite: **24 passed**.
- Meta-device parameter count for all four 100M configs: **100,202,256**.
- Mixer schedule: `R,R,R,A,R,R,R,A` (6 recurrent + 2 exact-attention layers).
- `scripts/count_params.py --meta` reports 100,202,256 parameters.
- Existing smoke test passes.
- Token-budget scheduler helper gives 152,588 nominal updates on 1 GPU and 76,294 on 2 GPUs for 10B tokens at 512 context, micro-batch 8, accumulation 16. Runtime termination uses the actual all-reduced supervised-token count rather than this nominal estimate.
- SFT configuration uses two dataset epochs and initializes from the completed pretraining `save_pretrained` directory.
- Remote-streaming and local-Parquet configuration files instantiate the identical model.

Not executed in the offline QA container:

- the 28+ GB FineWeb-Edu 10BT download;
- the UltraChat snapshot download;
- a CUDA/NCCL end-to-end 10B-token training run.

Those are external-data/GPU integration tests rather than model-construction tests.
